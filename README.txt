IMAGE UPDATE
This revision removes the illustrated SVG fallback panels that appeared instead of photographs.
The pages now use real photographs identified as G Convention Hall images from:
- the venue's own website gallery;
- the venue's public Justdial photo listing (including the Room photo category);
- the venue's WedMeGood and WeddingBazaar listings.

The photos are delivered through two image-caching CDNs (wsrv.nl and images.weserv.nl) because
some original image hosts did not reliably allow direct embedding. The JavaScript tries the
second delivery route if the first one fails. Internet access is required for these photographs.
